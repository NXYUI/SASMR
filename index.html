StreamingASMR

Google Drive에 보관한 음성 작품(ASMR)을 Windows와 Android에서 바로 스트리밍해 듣는 개인용 플레이어입니다.

기능

  • Drive의 라이브러리 폴더에서 작품 번호(RJ 번호) 폴더를 찾아 작품별로 정리합니다.
  • 분류 폴더별 목록, 트랙 스트리밍 재생과 구간 이동, 이어듣기를 지원합니다.
  • 작품 번호로 공개된 작품 정보를 가져오고, 제목과 트랙명을 번역해 보여줍니다. 번역은 사용자가 직접 고칠 수 있습니다.
  • 설정, 번역 수정, 이어듣기 위치를 사용자 본인의 Google Drive 앱 전용 폴더로 기기 간 동기화합니다.

Google 계정 데이터 사용

이 앱에는 별도 서버가 없습니다. 모든 처리는 사용자의 기기에서 이루어지며, 개발자는 사용자의 데이터를 받거나 저장하지 않습니다.

  • Google Drive 읽기 전용 권한: 라이브러리 목록을 만들고 오디오 파일을 재생하는 데만 씁니다. 파일을 바꾸거나 지우지 않습니다.
  • Drive 앱 전용 폴더 권한: 앱 설정과 번역 수정, 이어듣기 위치를 저장하는 데만 씁니다.

자세한 내용은 개인정보처리방침을 확인하세요.

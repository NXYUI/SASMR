StreamingASMR

개인정보처리방침

시행일: 2026년 10월 13일

1. 개요

StreamingASMR(이하 "앱")은 사용자의 Google Drive에 있는 음성 작품을 재생하는 개인용 앱입니다. 앱에는 별도 서버가 없으며 모든 처리는 사용자의 기기에서 이루어집니다. 개발자는 사용자의 개인정보나 Google 사용자 데이터를 수집·저장·전송받지 않습니다.

2. 앱이 접근하는 Google 사용자 데이터

권한접근하는 데이터사용 목적
Google Drive 읽기 전용
drive.readonly		 폴더와 오디오 파일의 이름·크기·위치, 오디오 파일 내용 라이브러리 폴더 안의 작품 목록을 만들고 오디오를 재생합니다. 목록을 만들기 위해 드라이브의 폴더 목록과 오디오 파일 목록을 읽지만, 사용자가 고른 라이브러리 폴더 밖의 항목은 표시하거나 저장하지 않습니다. 파일을 바꾸거나 지우지 않습니다.
Drive 앱 전용 폴더
drive.appdata		 앱이 만든 데이터만 앱 설정, 번역 수정, 이어듣기 위치를 사용자 본인의 Drive에 저장해 기기 간에 동기화합니다.
Google 계정 기본 정보 로그인 과정에서 Google이 제공하는 계정 식별 정보 로그인 상태를 유지하는 데만 씁니다.

3. 저장 위치

  • 사용자의 기기: 로그인 토큰(기기 보안 저장소), 작품 목록과 작품 정보 캐시, 앱 설정.
  • 사용자 본인의 Google Drive 앱 전용 폴더: 기기 간 동기화용 데이터. 이 폴더는 사용자 본인만 접근할 수 있으며 개발자는 볼 수 없습니다.

4. 외부로 보내는 정보

앱은 사용자가 쓰는 기능을 제공하는 데 필요한 경우에만 아래처럼 정보를 외부로 보냅니다.

  • 작품 정보 조회: 폴더 이름에서 찾은 작품 번호(예: RJ01234567)로 DLsite 웹사이트에서 공개된 작품 정보를 요청합니다. 작품 번호 외의 정보는 보내지 않습니다.
  • 번역: 사용자가 번역 기능을 쓰면 작품 제목, 트랙 이름 등 번역할 텍스트를 사용자가 설정한 번역 서비스(예: DeepL)로 보냅니다. 해당 서비스의 개인정보처리방침이 적용됩니다.

앱은 광고, 분석 도구, 추적 기술을 쓰지 않으며 어떤 데이터도 판매하거나 제3자와 공유하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한된 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

StreamingASMR's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. 데이터 삭제와 접근 취소

  • 앱에서 로그아웃하면 기기에 저장된 로그인 토큰이 삭제됩니다.
  • Google 계정의 서드 파티 연결 관리에서 앱의 접근 권한을 언제든 취소할 수 있습니다.
  • 동기화 데이터는 Google Drive 웹의 설정 → 앱 관리에서 StreamingASMR의 숨겨진 앱 데이터를 삭제해 지울 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 캐시와 설정도 함께 삭제됩니다.

Summary (English)

StreamingASMR has no server. It runs entirely on the user's device and the developer never receives user data. It uses drive.readonly only to list the user's chosen library folder and stream its audio files, and drive.appdata only to sync the app's own settings, translation edits and playback positions in the user's Drive. Work IDs (e.g. RJ01234567) taken from folder names are sent to DLsite to fetch public work information, and text the user chooses to translate is sent to the translation service the user configures. No data is sold, shared, or used for advertising or analytics.
